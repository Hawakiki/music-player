# music-player

내 컴퓨터나 휴대폰의 음악 폴더를 브라우저에서 바로 재생하는 플레이어입니다.

https://hawakiki.github.io/music-player/

## 설명

서버가 없는 정적 사이트입니다. 고른 폴더의 파일은 브라우저 안에서만 읽고, 어디에도 올라가지 않습니다. 곡 정보, 재생목록, 설정은 브라우저 저장소에 남습니다.

화면은 Poweramp나 UAPP 같은 전문 플레이어를 목표로 했습니다. 색은 무채색과 파란 포인트 하나로 두고, 나머지 색은 앨범 표지에서 나오게 했습니다.

### 시작하기

1. **폴더 추가**를 눌러 음악 폴더를 고릅니다. 폴더를 창으로 끌어다 놓아도 됩니다. 폴더는 여러 개 추가할 수 있습니다.
2. 하위 폴더까지 곡을 찾고, 별도 스레드에서 태그를 읽어 라이브러리를 만듭니다. 태그를 다 읽은 곡부터 라이브러리에 올라갑니다.
3. 다음에 다시 열면 폴더에 자동으로 다시 연결합니다(Chrome, Edge). 두 번째 방문에서 **다시 연결**을 누르고 "방문할 때마다 허용"을 고르면, 그다음부터는 열기만 해도 연결됩니다.

- 폴더를 옮기거나 지우면 "폴더를 찾을 수 없습니다"로 표시하고 **다시 선택**을 띄웁니다.
- 같은 폴더나, 이미 추가한 폴더의 안쪽·바깥쪽 폴더는 곡이 두 번 잡히지 않도록 거부합니다.
- 태그는 저장해 두고, 다음부터는 크기나 수정 시각이 바뀐 파일만 다시 읽습니다.

### 지원 형식

| 구분 | 형식 |
|---|---|
| 받는 확장자 | `mp3`, `m4a`, `m4b`, `aac`, `flac`, `wav`, `ogg`, `oga`, `opus`, `weba`, `mka` |
| 확장자로 제외 | `aif`, `aiff`, `ape`, `dff`, `dsf`, `tak`, `wma`, `wv` |
| 코덱으로 제외 | ALAC, ADPCM, GSM, Speex, DTS, MP2, TrueHD, 64bit float WAV |
| 브라우저마다 다름 | AC-3, E-AC-3: Edge는 재생, Chrome은 제외 |

- 확장자가 맞아도 안에 든 코덱을 브라우저가 재생할 수 없으면 라이브러리에 올리지 않습니다. 폴더 설명에는 "재생할 수 없는 형식 N개 제외"로 셉니다.
- AC-3와 E-AC-3는 지금 쓰는 브라우저에 재생할 수 있는지 물어서 정합니다.
- 코덱별 결과는 2026-11-07에 Windows의 Chrome과 Edge로 실제 파일을 재생해서 확인했습니다. 휴대폰은 확인하지 않았습니다.

### 라이브러리

- **화면:** 앨범, 아티스트, 장르, 폴더, 재생목록, 즐겨찾기, 최근 추가, 검색
- **앨범 묶기:** 앨범 아티스트 태그를 먼저 봅니다. 없으면 같은 폴더에 아티스트가 여럿인 앨범은 "여러 아티스트"로 묶습니다. 앨범 태그가 없으면 폴더 이름을 앨범 이름으로 씁니다.
- **디스크:** 디스크가 여러 장인 앨범은 디스크와 트랙 번호 순서로 나누어 보여 줍니다.
- **정렬:** 앨범은 아티스트순, 앨범순, 연도순, 최근 추가순으로 정렬합니다.
- **빠른 이동:** 앨범과 아티스트 목록 오른쪽에 초성·A–Z 인덱스가 있습니다.
- **검색:** 아티스트, 앨범, 곡 제목을 대소문자 구분 없이 찾습니다.
- **표지:**
  - 태그에 든 이미지를 먼저 씁니다. 없으면 같은 폴더나 바로 위 폴더의 `cover`, `folder`, `front`, `album`, `albumart` 이미지를 씁니다. CD1, CD2로 나뉜 앨범도 위 폴더의 이미지를 찾습니다.
  - 목록에는 384px 썸네일을 같은 표지당 한 번만 저장해 씁니다. 재생 화면에서는 원본을 파일에서 바로 읽습니다.
- **재생목록:**
  - 만들기, 이름 바꾸기, 삭제, JSON 내보내기와 가져오기를 할 수 있습니다.
  - 곡은 폴더 이름과 경로로 찾고, 파일을 옮겼으면 태그로 다시 찾습니다. 그래서 폴더를 다시 추가하거나 다른 PC에서 가져와도 곡을 찾습니다.
  - 못 찾은 곡은 지우지 않고 개수만 표시합니다.
- **곡 메뉴:** 다음에 재생, 대기열에 추가, 재생목록에 추가

### 재생

- **조작:** 셔플, 반복(끔, 전체, 한 곡). 대기열에서 원하는 곡으로 건너뛰기, 곡 빼기, 다음 곡 비우기
- **이어 듣기:** 마지막 곡, 재생 위치, 대기열, 볼륨을 기억해서 다시 열면 이어서 들을 수 있습니다.
- **키보드:** `Space` 재생과 일시정지, `←` `→` 5초 이동
- **미디어 키와 잠금 화면:** 재생, 일시정지, 이전, 다음, 탐색이 되고 표지도 보입니다.
- **오류 처리:** 재생할 수 없는 파일은 건너뛰고, 연속으로 실패하면 멈춥니다.
- **카드에서 바로 재생:** 데스크톱에서 앨범 카드에 마우스를 올리면 재생 버튼이 뜹니다. 재생 중인 앨범에서는 일시정지 버튼이 됩니다.
- **휴대폰:** 아래 탭(폴더, 앨범, 아티스트, 재생목록, 설정)과 작은 재생 막대로 바뀝니다. 백그라운드 재생 중 끊기지 않도록 출력 버퍼를 170ms로 잡았습니다.

### 재생 화면

- **배경:** 표지에서 가장 넓은 색을 뽑아 위쪽에 옅게 깝니다.
  - 채도는 낮게 묶어 눈이 편하게 했습니다.
  - 어두운 테마에서는 노랑 계열을 더 줄입니다. 그대로 두면 탁한 올리브색이 되기 때문입니다.
  - 색이 거의 없는 표지에는 색을 깔지 않습니다.
- **곡 전환:** 곡이 바뀌면 새 표지와 제목이 앞 표지 위로 0.3초 동안 겹쳐 나타나고, 배경 색도 서서히 바뀝니다. 기기에서 움직임 줄이기를 켜면 바로 바뀝니다.
- **파형 탐색:** 전체 화면을 열면 곡의 파형을 그리고, 파형을 눌러 이동합니다. 30분이 넘는 곡은 메모리 때문에 파형 대신 막대로 보여 줍니다.
- **오른쪽 탭:** 대기열, 이퀄라이저, 음향, 곡 정보
  - 곡 정보에는 태그, 길이, 크기, ReplayGain, 경로가 나옵니다.
- **형식 표시:** 아래에 파일 형식(`FLAC 96 kHz / 24 bit`, `MP3 320 kbps`)과 출력 샘플레이트를 보여 줍니다.

#### 표지 자리

설정에서 표지 자리에 보여 줄 것을 고릅니다.

- **앨범 표지:** 원본 해상도의 표지를 보여 줍니다.
- **LP:**
  - 앨범 표지를 라벨로 붙인 판이 33⅓ 또는 45rpm으로 돕니다. 재생하고 멈출 때 관성이 있습니다.
  - 톤암은 실제 12인치 LP의 홈 위치(바깥 146mm, 안쪽 60mm)를 따라 곡 진행에 맞춰 안쪽으로 들어갑니다.
  - 오른쪽 아래의 볼륨 노브는 앱 볼륨과 같은 값입니다. 손으로 잡고 중심을 따라 돌리면 돌린 각도만큼 돌고, 7시에서 5시 사이 끝에 닿으면 멈춥니다. 휠과 키보드로도 돌릴 수 있습니다.
- **카세트:**
  - 실제 컴팩트 카세트 구조를 따랐습니다. 라벨 칸에 제목, 아티스트, 시간, 코덱, 형식을 적고, 릴 사이 창으로 테이프가 보입니다.
  - 릴은 남은 테이프 양에 따라 크기가 바뀌고, 적게 감긴 쪽이 더 빨리 돕니다.
  - 곡이 바뀌면 오토리버스처럼 A면과 B면이 바뀌고, 릴이 반대로 돕니다.
  - 휴대폰에서는 카세트를 통째로 눕혀 보여 줍니다.
  - 라벨의 테이프 규격은 곡의 음질로 정합니다. 아래 표 참고.
- **VU 미터:**
  - 바늘이 실제 VU 미터처럼 300ms에 99%까지 움직이고, 살짝 넘쳤다가 돌아옵니다.
  - 0 VU 기준은 -18, -14, -10 dBFS 중에 고르고, 기본은 -10입니다.
  - 피크 표시는 +1 dBFS에서 켜집니다.
- **측정:**
  - 큰 칸 하나와 작은 칸 둘에 원하는 모듈을 넣습니다. 칸을 누르면 고르는 메뉴가 뜨고, 다른 칸에 있는 모듈을 고르면 두 칸이 자리를 바꿉니다.
  - 모듈은 스펙트로그램, 스펙트럼(가장 센 음의 음이름 표시), 레벨(피크와 순간 LUFS), 벡터스코프, 위상과 좌우, 오실로스코프, VU입니다.
  - LUFS는 ITU-R BS.1770의 K 가중치로 400ms 순간 음량을 잽니다.

카세트 테이프 규격:

| 라벨 | 곡 |
|---|---|
| TYPE I NORMAL POSITION | 손실 압축(MP3, AAC, Opus, Vorbis) |
| TYPE II CHROME POSITION | 무손실 24bit 미만 |
| TYPE III FeCr POSITION | 재생은 되지만 흔치 않은 파일. 아래 중 하나 |
| TYPE IV METAL POSITION | 무손실 24bit 이상 |

TYPE III에 해당하는 것:
- 드문 확장자: `aac`, `oga`, `weba`, `mka`, `m4b`
- 샘플레이트가 44.1·48kHz나 그 배수가 아닌 곡: 22.05kHz, 32kHz, 384kHz 등
- 3채널 이상: 5.1 등
- 16·24bit가 아닌 PCM: 8bit, 32bit float WAV 등

TYPE III가 다른 조건보다 먼저입니다. 모노는 옛 녹음에 흔해서 TYPE III로 치지 않습니다.

### 이퀄라이저

- 31Hz부터 16kHz까지 10밴드, 밴드마다 ±12dB에 프리앰프가 있습니다.
- 기본 프리셋: 평탄, 저음 강조, 고음 강조, 보컬 또렷하게, 저음과 고음 강조
- 지금 값을 내 프리셋으로 저장할 수 있습니다.
- 이퀄라이저를 끈 동안은 처리 과정을 건너뜁니다.

### 음향

재생 화면의 음향 탭에서 들으면서 바꿉니다. 설정은 곡이 바뀌어도 유지됩니다.

| 항목 | 내용 |
|---|---|
| 원음 듣기 | 모든 처리를 잠깐 건너뛰고 원음과 비교합니다. 저장하지 않습니다 |
| 저음, 고음 | ±12dB |
| 밸런스 | 좌우 음량 |
| 스테레오 폭 | 0~200%. 0%는 가운데로 모읍니다 |
| 모노 | 좌우를 합칩니다 |
| 크로스피드 | 약, 중, 강. 좌우가 심하게 갈린 녹음을 헤드폰으로 편하게 듣게 합니다 |
| 진공관 | 0~100%. 트라이오드는 2차 배음과 따뜻한 음색, 울트라리니어는 왜곡이 적고 평탄합니다 |
| 바이닐 | 약, 중, 강. 표면 잡음과 판 회전에 맞춘 미세한 흔들림입니다 |
| 저역 위상 보정 | 약, 중, 강(60, 120, 240Hz). 음량은 그대로 두고 저역 위상만 돌립니다 |
| 고역 복원 | 약, 중, 강. 압축으로 잘린 고역을 추정해서 채웁니다 |

진공관에 대해:
- 진공관은 곡선이 더한 왜곡만 뽑아 원음에 섞습니다. 큰 베이스가 보컬까지 찌그러뜨리지 않도록, 곡선에는 저역을 줄여서 넣습니다.
- 앰프 모드는 실제 앰프를 재현한 게 아니라 성격만 본뜬 것입니다.

고역 복원에 대해:
- 재생 중인 소리의 장기 평균에서 고역이 절벽처럼 잘린 지점을 찾습니다. 코덱이나 비트레이트 정보를 믿지 않기 때문에, 압축 음원을 FLAC으로 포장한 가짜 FLAC도 찾아냅니다.
- 잘린 지점 바로 아래 대역을 위로 옮겨 채웁니다. HE-AAC의 SBR과 같은 방식입니다.
- 채우는 크기는 곡 전체로 평균을 내서, 곡 안에서 흔들리지 않게 했습니다.
- 잘린 곳이 없는 곡은 출력이 원음과 비트까지 같습니다.
- 없어진 정보를 되살리는 게 아니라 추정입니다.

설정 화면에 있는 소리 항목:
- **음량 평준화:** 끔, 곡 기준, 앨범 기준. ReplayGain 태그로 곡마다 다른 음량을 맞추고, 태그가 없는 곡은 그대로 둡니다.
- **리미터:** 기본으로 켜져 있습니다. 효과로 소리가 커졌을 때 깨지지 않게 막습니다.

처리 순서는 음량 평준화, 고역 복원, 프리앰프, EQ, 저음과 고음, 진공관, 저역 위상, 바이닐, 스테레오 폭과 모노, 크로스피드, 밸런스, 리미터입니다.

### 설정

| 항목 | 선택 |
|---|---|
| 테마 | 자동, 블랙, 화이트. 자동은 기기의 다크 모드를 따르고, 바뀌면 바로 반영합니다 |
| 표지 자리 | 앨범 표지, LP, 카세트, VU 미터, 측정 |
| LP 회전 속도 | 33⅓, 45 rpm |
| 0 VU 기준 | -18, -14, -10 dBFS |
| 음량 평준화 | 끔, 곡 기준, 앨범 기준 |
| 리미터 | 켬, 끔 |

### 브라우저와 저장

| 브라우저 | 지원 |
|---|---|
| Chrome, Edge (데스크톱) | 모든 기능. 폴더 자동 재연결 |
| Android Chrome 132 이상 | 폴더 선택 가능. Galaxy S22에서 확인 |
| Firefox, Safari | 재생은 되지만 방문할 때마다 폴더를 다시 골라야 합니다 |

- **저장 위치:** 폴더 연결, 곡 정보, 표지 썸네일, 재생목록, 파형은 IndexedDB에 둡니다. 볼륨, 테마, 음향 설정, 이어 듣기 위치는 localStorage에 둡니다. 쿠키는 쓰지 않습니다.
- **오래 보관:** 브라우저가 데이터를 함부로 지우지 않도록 오래 보관을 요청합니다.
- **데이터가 지워지면:** 사이트 데이터를 지우면 폴더 연결과 곡 정보가 사라집니다. 폴더를 다시 고르면 복구되지만, 재생목록은 복구되지 않으니 내보내 두세요.

### 한계

- **비트퍼펙트 출력 불가:** 브라우저의 소리는 항상 OS 오디오를 거칩니다. UAPP나 Poweramp처럼 USB DAC로 직접 내보낼 수 없습니다.
- **샘플레이트 변환:** 브라우저 안에서 일어나서 끼어들 수 없습니다. 출력은 장치의 샘플레이트(보통 48kHz)로 나갑니다.
- **출력 정보:** 출력 장치 이름, 블루투스 코덱은 알 수 없습니다.

## 개발

```sh
npm install
npm run dev      # 개발 서버
npm run lint     # oxlint
npm run build    # 타입 검사 + 빌드 (dist/)
npm run preview  # 빌드 결과 확인
```

UI 컴포넌트 추가: `npx shadcn@latest add <component>`

설계 결정과 그 이유는 `docs/IDEA.md`에 있다.

## 시험

```sh
npm run build
npm run test:e2e -- --songs <곡 폴더>                # 전체
npm run test:e2e -- --songs <곡 폴더> --only 8,16    # 일부
npm run test:e2e -- --songs <곡 폴더> --long <파일>  # 아주 긴 파일 시험 포함
```

- 필요: ffmpeg, Edge, Chrome
- 곡 폴더에는 `tests/run.mjs`의 `SONGS`에 적힌 FLAC이 있어야 한다. 시험 파일은 이 곡들에서 만들어 `tests/out`에 둔다.
- 음원은 저장소에 올리지 않는다. 오디오 확장자는 `.gitignore`로 막혀 있다.
